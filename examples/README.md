# examples/ — 記入例

各ファイルをどう埋めるかの見本です。作品の正典ではありません（Claude は参照のみで、編集・矛盾チェックの対象にしません）。
不要になったらフォルダごと削除してかまいません。

- `kaze-no-tegami/` — 短編「風の手紙」。前提・キャラ 2 人・場所・用語集・シーン 1 つとその 3 媒体版、`/finalize` 後の状態記録と伏線台帳
- `shoutou-no-hi/` — 「消灯の日まで」。コマンドを一通り使った制作途中の作品。シーンをまたぐ状態記録・伏線台帳・確定の運用の見本

まず `kaze-no-tegami/` で各ファイルの埋め方を、長い作品の進め方は `shoutou-no-hi/` を見てください。
