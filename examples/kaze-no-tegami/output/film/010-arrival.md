# 脚本

```
○ 港町・坂道（夕）

　急な石段の坂。紬（22）が鞄を肩にかけ、息を切らして上ってくる。
　立ち止まり、振り返る。瓦屋根の向こうに夕日の海。

○ 坂上郵便局・窓口（夕）

　色の褪せた赤いポスト。紬が引き戸を開ける。
　窓口で六郎（68）が頬杖をついて眠っている。

紬「あの、本日付けで配属になりました、紬です。よろしくお願いします」

　反応がない。

紬「（大きく）よろしくお願いします！」

　六郎、片目だけ開ける。

六郎「ああ。六郎だ」

　六郎、立ち上がり、額の眼鏡を探しながら奥へ手招きする。

○ 同・奥の部屋（夕）

　天井まで届く棚に、空の木箱が並ぶ。

六郎「もうすぐ、風便の季節だ」
紬「かぜびん、ですか」
六郎「死んだ人からの手紙さ。秋の最初の北風の日にだけ届く」

　紬、思わず笑う。六郎は笑わず、木箱の埃を指で払う。

紬「……本当なんですか」
六郎「まあ、届くさ」

○ 港町・坂の上（夜）

　町に灯が点りはじめる。紬が立ち止まり、北の空を見上げる。
```
