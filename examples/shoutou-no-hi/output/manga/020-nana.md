# 020 ナナ（ネーム）

想定ページ数：16 ページ（通し P14〜P29。010 の 13 ページに続けて、P14 右ページ始まり）

- 010 の最後（P13 左・夜の光の帯）からめくった最初の見開き（P14〜P15）で、夜から朝へ切り替える。光の帯が「来なくなる」ことで夜明けを見せる
- ナナの階段の足音（カン　カン　カン）をここで初めて記号として出す。文字の大きさと間隔をそろえて「同じ間隔」を絵で見せ、汐里の足音（タッ　タタッ）は不ぞろいに描く
- 出来事 1・4・5 は台詞なし
- めくりの引きは、門を押す手（P19）・階段の上の光（P21）・「それ、名前？」（P23）・「……ナナ」（P25）・風の中のナナ（P27）に置く。命名の瞬間は、呼ぶ声を P25 の最後に置き、ナナが振り向く絵をめくった直後の P26 の大ゴマで受ける
- 配色は正典どおり（010 と同じ。塔は白一色、ナナは潮で褪せた白と赤）。ネームでは色を指定していない
