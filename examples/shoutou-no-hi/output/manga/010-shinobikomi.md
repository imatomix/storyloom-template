# 010 夜の灯台（ネーム）

想定ページ数：13 ページ（P1 左ページ始まり）

- 前半（岬 → 機械室 → 階段 → 灯室）は台詞なし。P1〜P5 に詰める
- ナナの登場は P5 最後のコマ（扉の音）で引き、めくった直後の P6 で大ゴマにする。足音は使わない
- 配色は正典どおり（`canon/locations/todai.md`・`canon/characters/lk-7.md`）。塔は白一色、ナナは潮で褪せた白と赤（塔の昔の配色）。夜のシーンなので、ネームでは色を指定していない
