## 作品全体の決めごと

2026-10-03、最初の `/draft novel 010` で作者が決定。文体の 5 観点は、010・020 の推敲の前に見直した。

- 視点：三人称一元（汐里視点）。汐里が知り得ないことは書かない
- 時制：過去形
- 表記：数字は漢数字（日誌の時刻・スマホの通知も含む）。型番「LK-7」は固有名詞としてそのまま
- 心の声：括弧は使わず、地の文に溶かす
- ルビ：必要になったら `|漢字《かんじ》` で振る
- 文の長さ：基調は短め。情景が広がる場面や感情が動く場面では、読点でつないだ長い文を混ぜて緩急をつける
- 語尾：「た」は全体の六割程度まで。現在形と体言止めを混ぜ、同じ語尾を四文以上続けない
- 段落の長さ：一文だけの段落は、間（ま）を作りたい箇所に絞る。描写は二〜四文の段落でまとめる
- 描写の密度：音・匂い・光・温度などの感覚描写を多めに。比喩は控えめに、使うなら一つの場面に一つまで
- 会話と地の文の比率：地の文中心。会話は短く、言葉の少なさで関係を見せる

## 文体の見本

最終便が出たあとの港は、思っていたより明るかった。桟橋の先の街灯が、黒い水面に長い光の筋を落としている。風が吹くたびに筋はほどけて、また一本に戻る。ロープのきしむ音。どこかの船で、ラジオが小さく天気予報を読んでいた。

ベンチは夜露で湿っていた。座ると、ジーンズ越しに冷たさがじわりと上がってくる。それでも立ちあがる気にはなれず、手の中の切符を何度も折り直しているうちに、角がすっかり丸くなってしまった。

明日の朝、六時十分。

それまでに決めればいい。そう思うと、少しだけ息がしやすくなる。
