# 消灯の日まで（制作途中の記入例）

廃止が決まった離島の灯台に家出してきた 14 歳の汐里と、停止命令が出ても「灯を絶やすな」の命令が優先されて止まれない旧式の灯台守ロボット LK-7（ナナ）の話。媒体は短編小説と短編映画。

このテンプレートのコマンドを一通り使って作った、**制作途中の状態**の見本です。`風の手紙` が「各ファイルの埋め方」の見本なのに対し、こちらは長い作品の運用（状態記録・伏線台帳・確定）の見本です。

## 読む順番

1. `STATUS.md` — 作品の現在地。どこまで決まり、何が残っているか
2. `canon/premise.md` → `canon/characters/` → `canon/locations/todai.md` — 正典
3. `output/novel/010-shinobikomi.md` → `output/novel/020-nana.md` — 小説本文。作品の中身をつかむならここから
4. `story/scenes/010-shinobikomi.md` — 小説の元になった骨格と、`## シーン設計`（場面ごとの見せ方）。映画版 `output/film/010-shinobikomi.md`（脚本）と読み比べると、同じ設計からの書き分けがわかる
5. `story/state.md`・`story/threads.md` — 010・020 を確定した後のキャラの状態と伏線台帳

## 文体と厚みの改善の経緯

この作品は、テンプレートの改善に合わせて二度書き直している。

**1. `/revise` による推敲（020）**

最初の小説版は「一文は短め」とだけ決めて書いたため、短い文が「〜た。」で延々と続く単調な文章になっていた。決めごとを 5 観点で書き直し、文体の見本を置いたうえで、`/revise` で推敲した。数値は `prose-stats.py` による。

| | 020 推敲前 | 020 推敲後 |
|---|---|---|
| 「た」で終わる文 | 89% | 49% |
| 現在形・体言止めなど | 11% | 51% |
| 同じ語尾の最大連続 | 31 | 3 |
| 最長の文 | 43 字 | 78 字 |
| 1 文だけの段落 | 55% | 44% |

推敲は 2 回に分けた。1 回目で原稿全体を見直し、2 回目で決めごとの「同じ語尾を四文以上続けない」から外れた箇所だけを直した。台詞は 1 行も変えていない。

**2. シーン設計からの書き直し（010）**

推敲だけでは、情景や心情の描写の少なさは補えなかった。そこでシーン設計を導入し、作者役（`docs/qa/author-persona.md`）が見せ場・心情の山・忘れられない具体を決めたうえで、010 を設計から書き直した。小説は約 3,400 字から約 5,200 字になった。この版はまだ `/revise` をかけておらず、同じ語尾の最大連続が 5 と、決めごとから外れている箇所が残っている。

## 作り方について

テンプレートの動作確認（QA）の工程で、AI（Claude）が作りました。人間の作者はいません。Claude が作者役として質問に答え、別の Claude Code のセッションがその答えを受けて各コマンドを実行しています。初期の作者役は「おまかせ」が多く、設定の細部はコマンド側の Claude の案がほとんどです。010 の書き直しでは、好みと判断基準を持たせた作者役（`docs/qa/author-persona.md`）を使っています。
