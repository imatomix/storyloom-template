# 四十五リットル（書き始めの記入例）

亡くなった祖母の家を、売却の引き渡しまでの三日間で、30 代の兄妹が片付ける話。迷わず捨てる兄の直哉と、手に取るたびに手が止まる妹の千秋は、言い争うこともなく、それぞれの速さで祖母を手放していく。媒体は短編小説（1〜2 万字）。

`/kickoff` から最初のシーン 010 を確定するまでの、**書き始めの段階**の見本です。`風の手紙` が「各ファイルの埋め方」、`消灯の日まで` が「長い作品の運用」の見本なのに対し、こちらは作品の始め方と、`/interview` で人物を確かめてから正典にする流れを見せます。

## 読む順番

1. `output/novel/010-daidokoro.md` — 小説本文（約 2,500 字）。作品の中身をつかむならここから
2. `canon/premise.md` → `canon/characters/chiaki.md` — 正典。前提と、主人公の千秋
3. `output/novel/README.md` — 小説の決めごと（視点・時制・文の長さなど）と、作者役が書いた文体の見本
4. `story/scenes/010-daidokoro.md` — 本文の元になった骨格と `## シーン設計`。作者役が決めた見せ場・心情の山・忘れられない具体
5. `workshop/sessions/` — 千秋へのインタビューの記録（2 回）
6. `STATUS.md` — 作品の現在地と、次にやること

## 意図的に残しているもの

書き始めの見本なので、次は未完成のままにしています。

- 兄の直哉の人物ファイルは無い。`canon/characters/chiaki.md` の関係の欄に、名前と年齢があるだけ
- `canon/glossary.md`・`story/structure.md`・`story/synopsis.md` は雛形のまま
- 年表（`canon/timeline.md`）は draft。祖母の入院・死去の時期と物語の季節は未定
- 小説は目安の 4,000 字より短い。作者役が「このまま」と判断して確定した
- `/check` が指摘した次の点は、直していない
  - シーン設計で「冷蔵庫の中身は書かない」と決めたのに、本文の「瓶どうしが鳴った」で中身がわかる
  - 場面 2 で、千秋の手がわずかに止まる（設計では場面 3 まで止まらない）
  - 「カーディガン」で季節がうっすらわかる
  - 状態記録に、直哉が二枚目の袋を広げたことが書かれていない

## 作り方について

この作品は、テンプレートの動作確認（QA）の工程で作りました（`docs/qa/confirm3/README.md`）。Claude が作者役（`docs/qa/author-persona.md`）として受け答えし、`claude -p` で実行した Claude Code がコマンドを動かしました。人間の作者はいません。

QA はテンプレートの一部を直す前に行ったため、記入例に入れるときに、ファイルを直した後の規則に合わせました。
- `related` のパスを、リポジトリのルートからのパスに揃えた
- 選ばなかったログライン案を、`rejected.md` から `ideas.md` の別案に移した
- 正典に入れた候補に `（→ 正典 …）` の印を付けた
- 正典に入れないと決めた候補を `rejected.md` に移した
- 昇格元の下書き（`workshop/drafts/characters/chiaki.md`）は削除した
