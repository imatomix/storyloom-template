## 作者役が設計で決めたこと

- 見せ場：白紙の最後のページ（3 案のうち一番地味な案）
- 心情の山：ナナの指が栞を直す一瞬。汐里が何に気づいたかは地の文でも説明しない
- 忘れられない具体：栞の紙の端の黒ずみ（当初「指の脂」→ ナナの指は金属なので機械油、と `/draft` が指摘して変更）
- 映像の狙いの欄からカメラの言葉を外させた

## 試作で見つかったテンプレートの課題

- 映像の尺の換算（200 字詰め 1 枚 ≈ 1 分）が、ト書き中心のシーンでは長く出すぎる（約 17 分と換算されたが、実感は 8〜10 分）
- QA 用の作業フォルダは Claude Code の信頼済みフォルダでないため、計測スクリプトの許可設定が効かず、`/draft` が文体を計測できなかった（テンプレートの不具合ではない）
