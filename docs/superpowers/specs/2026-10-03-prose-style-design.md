# 文体の調整 設計書

日付: 2026-10-03
前提: `docs/superpowers/specs/2026-10-03-storyloom-template-design.md`、`docs/superpowers/specs/2026-10-03-long-form-continuity-design.md`

## 背景

記入例「消灯の日まで」の小説版が単調だった。計測すると、地の文の平均は約 16 字、最長でも 44 字、文末の 84〜85% が「〜た。」だった。原因は 2 つ。

- 作品の決めごと（`output/novel/README.md`）が「一文は短め」だけで、緩急の指定が無かった
- 小説の書式ガイド（`.claude/skills/draft/references/novel.md`）に、文のリズムに関する観点が無かった

## 目的

作者が文体を決め、見本で示し、数値を見ながら推敲できるようにする。

## 1. 文体の観点（`references/novel.md`）

「決めること（作品全体で）」に、次の 5 観点を追加する。

| 観点 | 決める内容の例 |
|---|---|
| 文の長さ | 基調と緩急をつける場面（例: 基調は短め、情景と感情の山場では長く） |
| 語尾 | 「た」の比率の目安と、混ぜるもの（現在形・体言止めなど） |
| 段落の長さ | 1 文だけの段落を使う頻度 |
| 描写の密度 | 感覚描写・比喩の量 |
| 会話と地の文の比率 | 会話中心か、地の文中心か |

`/draft novel` は書き終えた後、決めごとと照らして外れている点を報告する（計測スクリプトがあれば使う）。

## 2. 文体の見本（`output/novel/README.md` の雛形）

テンプレートに雛形として置く。見出し:

- `## 作品全体の決めごと` — 視点・時制・表記・心の声・ルビと、上の 5 観点
- `## 文体の見本` — 作者が書いた数段落、または目指す文体の特徴

`/draft novel` と `/revise` は、書く前に必ずこのファイルを読む。見本がある場合は、決めごとよりも見本の実際の文章を優先して文体を合わせる。

## 3. /revise <シーン>

- 対象: 小説の原稿（`output/novel/NNN-*.md`）。脚本・ネームは対象外
- 手動専用にしない（会話の流れで Claude が使ってよい）
- 手順:
  1. 原稿、`output/novel/README.md`（決めごと・見本）を読む
  2. `python3 .claude/skills/revise/scripts/prose-stats.py <原稿>` で計測する。python3 が無い、またはスクリプトが失敗した場合は、計測なしで読んで指摘する
  3. 計測値と決めごとの差を示し、直す箇所を 3〜5 つ選んで「直す前 → 直した後」の案を出す
  4. 作者が承認した箇所だけ書き換える
- 出来事・事実・台詞の内容は変えない。変わった場合は `/finalize` のやり直しを促す。確定済みの原稿の status は変えない
- 原稿の `updated` は今日にする

## 計測スクリプト prose-stats.py

- Python 3 標準ライブラリのみ
- 入力: 原稿ファイルのパス（frontmatter は除いて計測）
- 区分: 「」『』で始まる行は会話、それ以外を地の文とする。地の文は 。！？ で文に区切る
- 出力（日本語のテキスト）:
  - 地の文の文数、会話の行数、会話の比率
  - 地の文の文長: 平均・最長、短（〜15 字）・中（16〜35 字）・長（36 字〜）の割合
  - 語尾の内訳: 「た」「る・う・い（現在形）」「体言止め・その他」の割合
  - 同じ語尾が連続した最大数
  - 段落数と、段落あたりの平均文数、1 文だけの段落の割合
- 終了コード: 正常 0、引数やファイルの誤り 2

## 記入例の更新

QA 用の作品で次を行い、記入例に反映する。

1. `output/novel/README.md` の決めごとを、緩急のある文体に書き換え、文体の見本を置く
2. `/revise` で 010 と 020 を推敲する
3. 推敲前後の計測値を `examples/shoutou-no-hi/README.md` に載せる
