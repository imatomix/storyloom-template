# 映像（脚本）の書式

日本の脚本書式で、脚本だけを書く。カット割り（絵コンテなど）は監督・絵コンテ担当の仕事として残し、書かない。

## 書式

```
○ 場所（時間帯）

　ト書き。現在形で、見えるもの・聞こえるものだけを書く。

人物名「台詞」
人物名（N）「ナレーション」
人物名（M）「モノローグ（心の声）」
人物名（OFF）「画面外の声」

　間

　ト書き。
```

## 書き方

- **柱（○）**: シーン設計の場面が変わり、場所か時間が変わるたびに立てる。回想・時間経過は `（回想）` `（数日後）` などを柱に添える
- **ト書き**
  - 見えるもの・聞こえるものを現在形で書く。カメラの指示（寄り・引き・パンなど）は書かない
  - 光の変化と音（環境音・効果音）を書き、場面の空気を作る。シーン設計の「感覚の細部」をここに置く
  - 心情そのものは書かず、動き・表情・手元・視線で示す
  - 一段落は短く。動きが変わるたびに段落を分ける
- **間**: 台詞のない時間は「間」と一行で書く。長い沈黙は、その間に何が見え、何が聞こえているかで書く
- **台詞**: 口に出す言葉だけ。説明台詞を避け、シーン設計の「台詞で言わせないこと」を台詞にしない
- **尺の目安**: 台詞の多い場面は、200 字詰め原稿用紙 1 枚でおよそ 1 分。ト書き中心の静かな場面は、原稿用紙の換算では長く出すぎるため、ト書き一段落を 3〜4 秒、台詞一つを 2〜5 秒として足し上げる。両方の見積もりが大きく違うときは、両方を作者に示す

## 書き終えた後の確認

- シーン設計のすべての場面が脚本にあるか。場所か時間が変わる場面の変わり目に柱が立っているか（同じ場所で続く場面には柱を立てない）
- 各場面の「感覚の細部」がト書きに書かれているか
- 台詞の無い場面が、ト書きだけで成立しているか
- 「台詞で言わせないこと」を台詞で言っていないか。ト書きに心情を書いていないか
- 尺が目安から 2 割以上外れていないか（外れたら理由を報告する）
