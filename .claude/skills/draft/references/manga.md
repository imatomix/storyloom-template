# 漫画（文字コンテ）の書式

漫画の文字コンテ（コマ割り・構図・人物・台詞などを文字で書いた設計図）を書く。到達点は、作画する人がそのまま下描きに入れる程度の情報量。日本の漫画の読み順（右から左、上から下）を前提にする。

## 書式

```
想定ページ数: 14

## P1（左ページ）
- ページの狙い: 夜の岬の静けさと、汐里の孤独を一枚で見せる
- めくり: 最後のコマで、塔の扉に手をかける

### コマ1（大・上段から中段のぶち抜き・横長）
- 構図: 引き。俯瞰で岬全体
- 人物: 汐里、画面の下端に小さく。リュックの肩紐を握っている。視線は塔
- 背景: 夜の岬。細い月。塔から伸びる光の帯が草地を横切る。描き込む
- 台詞: なし
- ナレーション: なし
- 効果音・効果: ザ…ン（遠い波）。光の帯は白抜き
- 間: 物語の始まりの静けさ。読者に一呼吸置かせる
```

## コマの項目

| 項目 | 書くこと |
|---|---|
| 大きさ・位置 | 大／中／小、ページ内の位置（上段右など）、形（横長・縦長・ぶち抜き・枠なし） |
| 構図 | 距離（引き・バスト・アップ・寄り）とアングル（俯瞰・煽り・目線） |
| 人物 | 誰が、どんな表情・ポーズ・演技で、どこを見ているか |
| 背景 | 場所・時間・天候と、描き込みの程度（描き込む／省略／白・ベタ） |
| 台詞 | 話者、吹き出しの種類（通常／叫び（トゲ）／心の声（もこもこ）／電話・機械（ギザ）／小・ゆれ線）と位置 |
| モノローグ・ナレーション | 枠の種類（角枠・枠なし） |
| 効果音・効果 | 描き文字、集中線・トーン・ベタフラッシュなど |
| 間 | 無言のコマの意図。読者に何を感じさせたいか |

該当しない項目は「なし」と書く（空欄にしない）。

## ページのルール

- 右綴じでは奇数ページが左、偶数ページが右に来る。偶数ページとその次の奇数ページは見開きで同時に目に入るため、ページをめくるのは奇数ページ（左）の後だけ
- 「めくりの引き」は奇数ページ（左）の最後のコマに置く。めくった直後の偶数ページ（右）の最初のコマに、引きを受ける絵を置く
- 開始ページが奇数（左）である前提。偶数始まりになる場合は作者に確認する
- 1 ページ 4〜7 コマを目安。シーン設計の見せ場は大ゴマ・ぶち抜き・見開きで
- フキダシ 1 つに 30 字程度まで。長い台詞は分ける
- 冒頭に想定ページ数を書く

## 書き終えた後の確認

- シーン設計のすべての場面がコマにあるか。見せ場に大ゴマ以上を使っているか
- 各ページに「ページの狙い」があるか。奇数ページの最後にめくりの引きがあるか
- 各コマの項目に空欄が無いか（作画する人が迷う箇所が無いか）
- 無言のコマに「間」の意図が書かれているか
- 「台詞で言わせないこと」を台詞・モノローグにしていないか
- ページ数が目安から 2 割以上外れていないか（外れたら理由を報告する）
