# 漫画（manga）の書式

ネーム（コマ割り・構図・台詞の設計図）を文字で書く。日本の漫画の読み順（右から左、上から下）を前提にする。

## 書式

```
## P1（左ページ）

### コマ1（大・横長）
- 構図: 引き。俯瞰で町全体
- 絵: 夕暮れの港町。坂の上に郵便局
- 台詞: なし
- 効果音: カーン カーン（鐘）
- ナレーション: 「この町には、死者からの手紙が届く」

### コマ2（小）
- 構図: バスト
- 絵: 主人公、窓口で居眠り
- 台詞: 主人公「……んあ」（フキダシ：小・ゆれ線）
```

## ルール

- 右綴じでは奇数ページが左、偶数ページが右に来る。偶数ページとその次の奇数ページは見開きで同時に目に入るため、ページをめくるのは奇数ページ（左）の後だけ
- 「めくりの引き」は奇数ページ（左）の最後のコマに置く。めくった直後の偶数ページ（右）の最初のコマに、引きを受ける絵を置く
- 開始ページが奇数（左）である前提。連載の掲載位置などで偶数始まりになる場合は作者に確認する
- 1 ページ 4〜7 コマを目安。見せ場は大ゴマ・ぶち抜き
- フキダシ 1 つに 30 字程度まで。長い台詞は分ける
- フキダシの種類: 通常／叫び（トゲ）／心の声（もこもこ）／電話・機械（ギザ）／小・ゆれ線（弱い声）
- 1 シーンの想定ページ数を冒頭に書く
