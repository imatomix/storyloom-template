# /draft — シーンを媒体の形式で書く

引数: $ARGUMENTS（1 つ目が媒体、2 つ目がシーン。足りなければ作者に聞く）

## 手順

1. 媒体の書式ガイドを読む: `references/film.md`（脚本）、`references/novel.md`（小説）、`references/manga.md`（漫画の文字コンテ）のうち該当するもの
2. 読む:
   - 対象シーンのファイル、その `related` にある canon/ のファイル、`canon/premise.md`（トーンと想定媒体）
   - 前後のシーン（番号が隣のもの）。次のシーンの「目的」を踏まえて、このシーンの引きを作る
   - `story/state.md`（登場キャラの現在の状態）と `story/threads.md`（状態が open の伏線）
   - 確定済みシーンの 1 行あらすじ一覧（`story/scenes/` の frontmatter の `summary:` を Grep で集める）
   - 同じ媒体の直前のシーンの原稿があれば、その末尾（文体と流れをつなぐため）
3. `output/<媒体>/README.md`（作品全体の決めごと・文体の見本）があれば読み、従う。同じ媒体の `output/` に既存の原稿があれば読み、文体・書式を合わせる
4. **シーン設計**: 対象シーンの `## シーン設計` を確かめる
   - 空なら設計を作る。作者に「見せ場」と「心情の山」を尋ね、「おまかせ」なら 2〜3 案を示して選んでもらう。「忘れられない具体」も作者に一つ選んでもらう
   - シーンを場面（脚本なら柱が立つ程度のまとまり）に分け、場面ごとに見せるもの・感覚の細部・心情（外／内）・台詞で言わせないことを書く
   - 媒体ごとの分量の目安と狙いは、`canon/premise.md` の想定媒体にある媒体だけ書く
   - 設計を作者に見せ、**承認を得てから**シーンファイルに書き込む。承認前に本文を書かない
   - 既に設計があれば作り直さない。今回の媒体の行が表に無ければ、その行だけ足す案を示して承認を得る
5. `output/<媒体>/<シーンと同じファイル名>.md` に、シーン設計に沿って書く。既にあるなら上書きせず、改稿か別案（`-alt` を付けたファイル名）かを作者に聞く
   frontmatter:
   ```yaml
   ---
   status: draft
   related:
     - story/scenes/<シーンファイル名>
   updated: YYYY-MM-DD
   ---
   ```
6. **書き終えた後の確認**: 書式ガイドの「書き終えた後の確認」を行い、結果を作者に報告する。分量が目安から 2 割以上外れたら、理由を添える
7. 正典に無い新しい事実（新しい固有名詞・過去の出来事など）を書いた場合は、一覧で作者に伝え、`/canonize` の候補にする
8. このシーンで触れた伏線（張った・回収した・進めた）を `story/threads.md` の ID で報告する。台帳の更新は作者が原稿を直し終えた後の `/finalize` で行う
9. 迷った箇所を 1〜3 個挙げて作者の判断を仰ぐ
